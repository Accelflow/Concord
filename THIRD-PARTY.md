# Third-party dependencies

This source snapshot lists its Rust dependencies in `Cargo.lock` and its
Vitest development dependencies in the fixture and demo `pnpm-lock.yaml`
files. Cargo and pnpm fetch these packages separately. The snapshot contains
no vendored packages, node_modules, or prebuilt Concord binaries.

Each third-party package retains its upstream license. For any binary
distribution, inspect the dependencies actually included for that target and
carry the applicable license texts, attribution and upstream notices alongside
the binary. This document describes the source snapshot.
